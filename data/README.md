# Data

No data file is stored in this repository. The notebooks and `src/preprocess.py` download
30 random surgical cases (all five vitals present, seed 42) directly from VitalDB
(https://vitaldb.net, also on PhysioNet: https://physionet.org/content/vitaldb/1.0.0/).
VitalDB is open data (Lee et al., *Scientific Data*, 2022).
